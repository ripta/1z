# Getting Started with 1z

1z is a stack-based, concatenative programming language written in Zig.

If you have programming experience but are new to stack languages, start here:

1. [Installation](installation.md) -- build 1z from source
2. [The REPL](repl.md) -- explore the language interactively
3. [Your First Program](first-program.md) -- write and run a `.1z` file

Once you are comfortable with the basics, the
[API Reference](../reference/index.md) documents every word in the standard
library.
