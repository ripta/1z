# Language Tutorials

These tutorials build real fluency with 1z. They go deeper than the
[first program walkthrough](../getting-started/first-program.md), with
progressive examples you can run and modify. Read them in order -- each
one assumes familiarity with the previous ones.

1. [Stack Fundamentals](stack-fundamentals.md) -- the mental model, shuffle
   words, and stack effects
2. [Quotations](quotations.md) -- code as data, combinators, curry and compose
3. [Defining Words](defining-words.md) -- anatomy, conventions, and composition
4. [Control Flow](control-flow.md) -- conditionals, loops, iteration, and error
   handling

All examples are runnable. Save any snippet to a `.1z` file and run it with
`./zig-out/bin/1z file.1z`.

The [Conceptual Guides](../guides/index.md) go deeper into the type system,
modules, iterators, concurrency, async I/O, and FFI.

The [Cookbook](../cookbook/index.md) collects common patterns and idiomatic
recipes.

The [Cheatsheet](../cheatsheet.md) is a compact reference for all syntax
and standard words.

The [API Reference](../reference/index.md) documents every word in the
standard library.
